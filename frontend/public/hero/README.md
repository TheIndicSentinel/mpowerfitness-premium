# Hero Gallery Images

Place 4 brand images here named exactly:

  1.jpg  (slide 1 — e.g. raw strength / iron)
  2.jpg  (slide 2 — e.g. conditioning / sweat)
  3.jpg  (slide 3 — e.g. focus / discipline)
  4.jpg  (slide 4 — e.g. transformation / win)

Supported formats: .jpg, .jpeg, .png, .webp
If using .png or .webp, rename to match the number (e.g. 1.png, 2.webp).

Images should be portrait/tall ratio (e.g. 800×1100px) and high contrast
so text overlays remain readable. The app will automatically display them
in the rotating hero gallery and fall back to the blueprint placeholder
panel if an image is missing.
